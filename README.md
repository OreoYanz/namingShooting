# 台灣改名助手

單機 **網頁版**：融合 **八字喜用神（扶抑＋調候）**、**十二生肖學**、**康熙筆畫三才五格**。  
瀏覽器介面 + 本機 Python 引擎（同一套評分規則）。

命理僅供文化參考，用字與改名請向戶政確認。

## 換到新電腦怎麼開

1. 在開發機執行 `scripts\build_exe.bat`（產生 `dist\TaiwanNamingHelper\`）
2. 把**整個專案資料夾**（含 `dist`、`啟動.bat`）拷到新電腦
3. 雙擊 **`啟動.bat`**
4. 瀏覽器自動開啟 `http://127.0.0.1:8765/`

不必在新電腦安裝 Python。請**保持黑色視窗開啟**；關閉即停止服務。

> 不要只開 `web\index.html`（沒有本機後端無法分析）。

### 開發機直接跑（有 Python）

```bat
python -m pip install -r requirements.txt
python main.py
```

或雙擊 `啟動.bat`。

測試：

```bat
python -m pytest -q
```

## 主要功能

- 新生兒命名／成人改名（原名評估、改名原因、改善方向、原名 vs 新名）
- 改姓、字輩、單雙名、忌用字可設定
- 避開近五年熱門名／經典菜市場名
- Ranking → Top 50、推薦分類、詳情與推薦理由
- 介面：深墨青 × 暖紙白 × 赤銅點綴

## 匯入菜市場名

格式見 `data/hot_names_template.csv`（進階可於開發環境匯入資料庫）。

## 規則摘要（V1）

- 月柱用節氣；喜用神用字義五行，三才五格用康熙筆畫五行
- 硬規則只淘汰負面諧音／粗俗／明顯負面／禁用／無法讀寫
- 綜合評分權重為**內部系統規則**，不對外公開於品牌官網；調整權重僅需改引擎／規則檔，不必改網站文案
- 詳見 `data/*_rules.json`

資料出處見 `data/ATTRIBUTION.txt`。
