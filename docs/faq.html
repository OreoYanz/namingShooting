常見問題

關於名序服務的常見疑問。

名序的命名流程是什麼？

命理分析 → 多維尋名 → 候選篩選 → 專業甄選 → 名字成章 → 珍藏。由名序團隊依此六步完成，全程專人把關。查看完整說明

購買流程是什麼？

選擇服務 → 提供資料（官方 Line）→ 確認匯款 → 命理與姓名分析 → 提供候選 → 選定名字 → 命名解析／故事／七言祝福 → 完成交付。查看完整說明

名序提供哪些服務？

新生兒命名、成人改名、流年分析，以及命名故事、七言詩、手寫紀念等完整內容產出（依方案）。

需要提供哪些資料？

性別、出生日期時間、出生地、姓氏；改名需原姓名；可選填父母姓名、字輩、喜歡或避開的字。

如何進行綜合評估？

名序從多個面向進行綜合評估，包括命理契合、五行配置、姓名結構、音韻流暢、字義與文化意涵、名字整體氣質、日常使用感、名字辨識度；不以單一筆畫或單一規則決定結果。

會提供多少組候選名字？

依方案與探索程度，通常提供數十組通過篩選的候選，並附評等與說明，供您挑選。

可以指定命名風格嗎？

可選傳統命理、現代、文學、小眾或綜合推薦等模式，也可指定喜用字。

如果不喜歡候選名字怎麼辦？

可調整偏好、避開用字或重新分析；依方案規範提供修訂或加購服務。

七言詩是必備的嗎？

完整內容方案含七言四句祝福詩，取其意象，不硬嵌姓名。

手寫紀念品是什麼？

手寫命名卡或手寫稿形式，呈現寓意、祝福與詩句，可收藏或紀念。

流年分析可以看幾年？

依方案提供一甲子（60 年）的流年分析；實際年數依需求而定。

名序是算命嗎？會保證改運嗎？

名序提供文化命理參考與命名設計，不宣稱保證改運、發財或健康。我們強調理解、選擇、祝福與紀念。
