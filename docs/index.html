品牌故事

一個名字，是人生最初的序章。姓名只有兩、三個字，卻承載著父母的期盼、家人的祝福，也記錄著一個人出生時的時間與故事。

「名」是名字，也是人生的名章；「序」是次序，也是人生故事的序章。名序做的不是單純的取名，而是替一個人的人生，寫下第一行值得珍藏的文字。
